# Workshop: Dominando Prompts em JSON

Aplicação web interativa para o workshop de 35 a 45 minutos sobre engenharia de prompts estruturados em JSON, conduzido em dupla por Pessoa 1 e Pessoa 2.

## Como rodar o projeto

```bash
# Instalar dependências
npm install

# Rodar servidor de desenvolvimento
npm run dev
```

Acesse [http://localhost:5173/](http://localhost:5173/) no navegador.

## Recursos
- **Apresentação com 20 slides**: navegação por teclado (`←`/`→`, `Espaço`), notas do apresentador (`N`), índice geral (`I`), tela cheia (`F`).
- **Laboratório / Atividade**: Construtor com preview ao vivo de JSON, 6 exemplos prontos (RH, Vendas, Marketing, Jurídico, Suporte, Financeiro) e checklist interativo com persistência local.
